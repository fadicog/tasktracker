🔒 Encrypt Token

One-time tool — encrypts your GitHub PAT with the tracker password so it can be safely committed to the repo. Everything runs locally in your browser; nothing is sent anywhere.
⚠ Verify you're on the legitimate fadicog/tasktracker page (or open this file locally). Never paste your PAT into an untrusted page.
(empty)

After you have the output:

  1. Click Copy output
  2. Open github.com/fadicog/tasktracker
  3. Click Add file → Create new file (or edit if it exists)
  4. Name it token.enc
  5. Paste the JSON content, scroll down, click Commit changes
  6. Done — open the tracker on any device, enter TDRA2026, edits will save automatically

To rotate the token later:

  1. Generate a new fine-grained PAT on github.com/settings/tokens
  2. Re-open this tool, re-encrypt, replace token.enc
  3. All users pick up the new token on their next page load — they do nothing
